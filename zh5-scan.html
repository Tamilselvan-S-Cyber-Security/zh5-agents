ZH5 Scan

AI agentic bug bounty hunter — recon, scan, validate, and submission-ready reports. By ZH5 · Tamilselvan-S-Cyber-Security.

Get on GitHub ZH5 Agent ZH5.club

1. Install

Clone the ZH5 Agentic Bug Hunter repo and run the standalone installer. Creates the zh5 command on your PATH.

git clone https://github.com/Tamilselvan-S-Cyber-Security/zh5-agent && cd zh5-agent && ./install.sh --agent standalone

Optional free local AI (Ollama)

curl -fsSL https://ollama.ai/install.sh | sh
ollama pull qwen2.5:14b
zh5 setup

2. Core Commands

Full ZH5 scan

zh5 scan target.com

Recon only

zh5 recon target.com

Validate a finding

zh5 validate "IDOR on /api/user?id=123"

Write a submission-ready report

zh5 report

Interactive chat

zh5 chat

4. Workflow

  1. Install — ./install.sh --agent standalone
  2. Configure — zh5 setup (Ollama / Groq / Claude / etc.)
  3. Recon — zh5 recon target.com
  4. Scan — zh5 scan target.com
  5. Validate — zh5 validate "…" (7-Question Gate)
  6. Report — zh5 report for HackerOne / Bugcrowd / Intigriti / Immunefi
