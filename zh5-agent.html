Install & Run

git clone https://github.com/Tamilselvan-S-Cyber-Security/zh5-agent && cd zh5-agent && ./install.sh --agent standalone
zh5 setup
zh5-agent target.com

Manual loop (same pipeline)

zh5 recon target.com
zh5 scan target.com
zh5 validate "finding"
zh5 report

Responsible Use

  • Only scan targets you are authorized to test
  • Stay inside bug bounty program scope and rate limits
  • Review agent findings before submission
